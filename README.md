# 西安外国语大学 · 2026 新生通关宝典

面向 2026 级新生的单页静态网站，涵盖 10 大模块：

| 模块 | 内容 |
|---|---|
| ⏱️ 30 秒了解西外 | 学校概况、国家级/省级一流专业 |
| 🗺️ 长安校区 | 校区地图、主要地点、到校交通 |
| 🛏️ 宿舍 | 门禁、熄灯、限电、洗衣、洗澡等 |
| 🍜 食堂 | 食堂分布、支付方式（电子饭卡/一卡通） |
| 🧭 报到全流程 | 线上准备 → 报到 → 缴费/户籍/医保 |
| 🎒 开学必备清单 | 可勾选，进度自动保存在本机浏览器 |
| 💪 军训生存指南 | 军训时间、物品、经验 |
| 📚 升学攻略 | 教改班（ACCA/CIMA/CFA/国经班）、转专业、卓越班、英语分级、辅修 |
| 🛡️ 防骗攻略 | 官方安全提示 + 常见骗局识别 |
| 💡 校园服务 | 网办大厅、掌上西外、常用电话与链接 |

## 如何使用

- **本地查看**：直接用浏览器双击打开 `index.html` 即可（无需安装任何环境）。
- **分享给新生**：把整个 `xisu-guide` 文件夹打包发送；或部署到任意静态托管（如 GitHub Pages），上传整个文件夹即可。
- **清单进度**：勾选进度保存在浏览器 localStorage 中，同一设备同一浏览器再次打开会自动恢复；"重置进度"按钮可清空。

## 目录结构

```
xisu-guide/
├── index.html             # 主页面（所有内容都在这里，方便直接修改）
├── manifest.webmanifest   # PWA 清单（手机"添加到主屏幕"）
├── 404.html               # 自定义 404 页面
├── sitemap.xml            # 站点地图（SEO）
├── robots.txt             # 爬虫规则（SEO）
└── assets/
    ├── css/style.css      # 样式（学院墨青主题：墨青主色+古金+朱印红点缀，改 :root 配色变量即可换肤）
    ├── js/app.js          # 交互脚本 + 必备清单数据（CHECKLIST 数组）
    └── img/               # campus-map.webp 地图、og-share.png 分享图、图标 PNG 等
```

## 修改内容

- **文字内容**：直接编辑 `index.html` 中的对应区块，每个模块都有注释标注。
- **必备清单增减条目**：编辑 `assets/js/app.js` 顶部的 `CHECKLIST` 数组（含分类、条目、备注）。
- **换配色**：修改 `assets/css/style.css` 中 `:root` 里的 `--red`、`--gold` 等变量。
